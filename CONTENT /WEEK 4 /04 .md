## Week 4 — Pattern Matching and Text Processing
> 💡 **One-line summary:** Week 4 focuses on mastering text-processing efficiency through shell globs and the application of Basic, Extended, and Perl-Compatible Regular Expressions using tools like `grep`, `cut`, `tr`, `paste`, and `fold`.

---

### 🔑 Core Concepts

#### Pattern Matching
Pattern matching is the process of filtering text using template sequences. It encompasses two distinct mechanisms: **Globs** (shell-level filename expansion) and **Regular Expressions** (text-level pattern searching within files or streams).

> 📝 **Exam note:** Never confuse globs with regex — globs operate on filenames *before* a command runs, while regex operates on text content *inside* files or streams.

---

#### Regular Expression (Regex)
A **Regular Expression** is a template sequence of characters used by string-searching algorithms to filter or find text within documents. POSIX defines two standard engines: **BRE** and **ERE**.

---

#### BRE (Basic Regular Expression)
The default POSIX regex engine used by tools like `grep` and `sed`. In BRE, special operators such as grouping and certain quantifiers require backslash escaping to activate their special meaning: `\(`, `\)`, `\+`, `\?`, `\{`, `\}`.

> 📝 **Exam note:** In BRE, `+` is a *literal* plus character; you must write `\+` for the "one or more" quantifier. This is the **opposite** of ERE.

---

#### ERE (Extended Regular Expression)
A variant engine enabled via `grep -E` or the *deprecated* `egrep` command. ERE supports symbols like `+`, `?`, `{n,m}`, `( )`, and `|` as special operators **without** escaping.

> 📝 **Exam note:** `egrep` is deprecated in newer systems — always use `grep -E` in exam answers.

---

#### PCRE (Perl-Compatible Regular Expression)
An advanced engine enabled via `grep -P` that supports complex features like **look-aheads**, **look-behinds**, **minimal (ungreedy) matching**, **named subpatterns**, and **recursive patterns**.

---

#### Glob (Shell Filename Expansion)
A **Glob** is a shell-level pattern-matching mechanism used for **filename expansion** before a command is executed. The shell expands the glob into a list of matching filenames, and only that list is passed to the command.

| Glob Wildcard | Meaning |
|---|---|
| `*` | Matches any string of characters (including empty) |
| `?` | Matches exactly **one** character |
| `[abc]` | Matches any one character listed inside the brackets |
| `[!abc]` | Matches any character **NOT** listed inside the brackets (uses `!`, not `^`) |

> 📝 **Exam note:** Glob negation uses `!` inside brackets (e.g., `[!abc]`), whereas regex negation uses `^` (e.g., `[^abc]`). Don't mix these up.

---

#### Anchors (`^`, `$`)
Meta-characters that match a **position** rather than a character. `^` matches the start of a line and `$` matches the end of a line.

---

#### Quantifiers
Symbols specifying how many times a preceding character or group should repeat:

| Quantifier | Meaning | BRE Syntax | ERE Syntax |
|---|---|---|---|
| Zero or more | Match 0+ occurrences | `*` | `*` |
| One or more | Match 1+ occurrences | `\+` | `+` |
| Zero or one | Match 0 or 1 occurrence | `\?` | `?` |
| Exact count | Match exactly *n* times | `\{n\}` | `{n}` |
| Range | Match *n* to *m* times | `\{n,m\}` | `{n,m}` |
| At least *n* | Match *n* or more | `\{n,\}` | `{n,}` |
| At most *n* | Match up to *n* times | `\{,n\}` | `{,n}` |

---

#### Character Classes
Predefined POSIX sets used to match specific types of characters regardless of locale settings. They must be used inside an outer pair of brackets: `[[:class:]]`.

| Class | Matches |
|---|---|
| `[[:digit:]]` | All numeric digits `0-9` |
| `[[:alpha:]]` | All alphabetic characters |
| `[[:alnum:]]` | Alphanumeric (alpha + digit) |
| `[[:lower:]]` | Lowercase alphabetic characters |
| `[[:upper:]]` | Uppercase alphabetic characters |
| `[[:blank:]]` | Space and tab |
| `[[:space:]]` | All whitespace (space, tab, newline, etc.) |
| `[[:punct:]]` | Punctuation characters |
| `[[:xdigit:]]` | Hexadecimal digits (`0-9`, `A-F`, `a-f`) |
| `[[:graph:]]` | Graphical characters (alnum + punct); **excludes** space |
| `[[:print:]]` | Printable characters (alnum + punct + space) |
| `[[:cntrl:]]` | Control characters (octal `000`–`037`, `177`) |

> 📝 **Exam note:** **Locale impacts ranges.** In `en_US.UTF-8`, `[a-d]` might match `[aBbCcDd]`. Use `LC_ALL=C` for traditional ASCII-order interpretation.

---

#### Backreferences (`\1` to `\9`)
A method to refer back to a previously matched parenthesized subexpression within the same regex. For example, `\(hello\).*\1` matches a line containing "hello" followed by any characters and then "hello" again.

---

#### Word Boundary (`\b`)
An anchor that matches the empty string at the beginning or end of a word (where a word character meets a non-word character).

- `\b` — Word boundary (start or end of a word)
- `\B` — **Non**-word boundary (position *not* at a word edge)
- `\<` — Start of a word specifically
- `\>` — End of a word specifically

> 📝 **Exam note:** `\b` matches word boundaries **anywhere** in a line, whereas `^` and `$` match only the start and end of the **entire line**.

---

#### Alternation (`|`)
A logical **OR** operator used to match one of multiple patterns. In BRE, it is written as `\|`; in ERE, simply `|`.

---

#### Squeezing
A `tr` operation (`-s` flag) that replaces multiple consecutive occurrences of a character with a single occurrence.

---

#### Operator Precedence

##### BRE Precedence (Highest to Lowest)
1. `[..] [==] [::]` — Collation-related bracket symbols
2. `\metachar` — Escaped meta-characters
3. `[ ]` — Bracket expression
4. `\( \)` — Subexpressions / Grouping
5. `* \{ \}` — Repetition / Quantifiers
6. Concatenation
7. `^ $` — Anchors

##### ERE Precedence (Highest to Lowest)
1. `[..] [==] [::]` — Collation-related bracket symbols
2. `\metachar` — Escaped meta-characters
3. `[ ]` — Bracket expression
4. `( )` — Grouping
5. `* + ? { }` — Repetition / Quantifiers
6. Concatenation
7. `^ $` — Anchors
8. `|` — Alternation (lowest priority)

> 📝 **Exam note:** Alternation `|` has the **lowest** precedence in ERE. Use parentheses to group alternatives when combining with other operators.

---

#### Collating Symbols & Equivalence Classes
- **Collating Symbol `[[.ch.]]`**: Treats a digraph (like `ch`) as a single character for matching and sorting purposes.
- **Equivalence Class `[[=a=]]`**: Matches `a` and all its accented variants (`á`, `à`, `â`, etc.).

---

#### PCRE Advanced Features
- **Look-ahead Assertions:** `(?=...)` (positive), `(?!...)` (negative) — assert what follows without consuming characters
- **Look-behind Assertions:** `(?<=...)` (positive), `(?<!...)` (negative) — assert what precedes without consuming characters
- **`\K` Operator:** Resets the start of the current match; useful for variable-length look-behinds
- **Minimal (Ungreedy) Matching:** `*?`, `+?`, `??` — match the **shortest** possible string instead of the longest
- **Named Subpatterns:** `(?P<name>...)` — allows referring to captured groups by name rather than number
- **Recursive Patterns:** `(?R)` — allows a pattern to refer back to itself (e.g., for balanced parentheses)

---

#### Shell Mechanics & Exit Status
- **Exit Status (`$?`):** After `grep` runs, `$?` holds **0** if a match was found, **1** if no match was found.
- **Glob Expansion:** Performed by the **shell** (not the command) before command execution; the command only sees the resulting list of filenames.

---

#### Escape Codes (PCRE / Advanced)

| Escape | Matches |
|---|---|
| `\d` | Any digit (equivalent to `[0-9]`) |
| `\D` | Any non-digit |
| `\s` | Any whitespace character |
| `\S` | Any non-whitespace character |
| `\w` | Any word character (`[a-zA-Z0-9_]`) |
| `\W` | Any non-word character |

**Non-graphical escapes:** `\a` (alert/bell), `\f` (form feed), `\n` (newline), `\r` (carriage return), `\t` (tab), `\v` (vertical tab), `\0` (null), `\cx` (control-x)

**Numeric escapes:** `\xxx` (hex), `\oxxx` (octal), `\dxxx` (decimal)

---

#### Multiline Anchors
- `\'` — Matches the start of the entire pattern space
- `\'` — Matches the end of the entire pattern space

### ⌨️ Commands & Syntax

#### `grep` — Search for patterns in text

| Command | Syntax | What it does |
|---|---|---|
| `grep` | `grep 'pattern' file` | Searches for and prints lines matching the specified pattern |
| `grep` | `command \| grep 'pattern'` | Filters piped output for lines matching the pattern |

**Key flags reference:**

| Flag | Effect |
|---|---|
| `-E` | Uses the **Extended Regular Expression (ERE)** engine |
| `-P` | Uses the **Perl-Compatible Regular Expression (PCRE)** engine |
| `-F` | **Fixed string** search; treats every character (like `*` or `.`) literally — no regex |
| `-i` | Performs a **case-insensitive** search |
| `-v` | **Inverts** the match; displays lines that do NOT contain the pattern |
| `-o` | Prints **only the matching part** of the line, each match on a new line |
| `-c` | Displays the **count** of matching lines instead of the lines themselves |
| `-n` | Prefixes each output line with its **line number** from the file |
| `-w` | Matches the pattern only as a **whole word** |
| `-x` | Matches only if the pattern spans the **entire line** |
| `-f file` | Reads patterns from the specified file, one per line |
| `-e PAT` | Allows specifying **multiple patterns** (logical OR across patterns) |
| `-q` | **Quiet mode**; suppresses output and only returns an exit status (`0` for match, `1` for no match) |
| `-m [n]` | Stops reading a file after **n** matches |
| `-l` | Prints only the **filename** of files containing a match |
| `-H` | Prints the **filename** with each match (default for multiple files) |
| `-h` | **Suppresses** filename printing |
| `-r` | Searches **recursively** through directories |
| `-A [n]` | Prints **n** lines of context **after** each match |
| `-B [n]` | Prints **n** lines of context **before** each match |
| `-C [n]` | Prints **n** lines of context **before and after** each match |

---

#### `cut` — Extract columns or segments from text

| Command | Syntax | What it does |
|---|---|---|
| `cut` | `cut -c [range] file` | Extracts a specific **character range** (e.g., `1-4`) from each line |
| `cut` | `cut -d' ' -f [n] file` | Extracts the n-th **field** using a specified delimiter (default is tab) |
| `cut` | `cut -b [range] file` | Extracts specific **bytes** (numbered from 1); differs from `-c` for multi-byte characters |

**Key flags reference:**

| Flag | Effect |
|---|---|
| `-c` | Select by **character** positions |
| `-b` | Select by **byte** positions |
| `-d` | Specify a **delimiter** (default: tab) |
| `-f` | Specify **field** numbers to extract |
| `--complement` | Extract all fields/characters **EXCEPT** those specified |
| `--only-delimited` | Suppresses lines that do **not** contain the delimiter |
| `--output-delimiter=STR` | Changes the string used to separate fields in the **output** |

---

#### `tr` — Translate, delete, or squeeze characters

| Command | Syntax | What it does |
|---|---|---|
| `tr` | `tr 'set1' 'set2'` | **Translates** characters in set1 to corresponding characters in set2 from stdin |
| `tr` | `tr -d 'set'` | **Deletes** all characters in the specified set from the input |
| `tr` | `tr -s 'char'` | **Squeezes** repeated occurrences of the specified character into one |

**Key flags reference:**

| Flag | Effect |
|---|---|
| `-d` | **Delete** all characters in the specified set |
| `-s` | **Squeeze** repeated consecutive characters into one |
| `-c` | Operate on the **complement** of the specified character set |

**`tr` mapping rules:**
- **Many-to-one** mapping is supported; **one-to-many** is NOT
- If LIST2 is shorter than LIST1, the **last character** of LIST2 is repeated to match the length of LIST1
- LIST2 repetition syntax: `[c*n]` repeats character `c` for `n` times

---

#### `paste` — Merge files horizontally

| Command | Syntax | What it does |
|---|---|---|
| `paste` | `paste file1 file2` | Merges lines of files **horizontally**, separated by a tab or specified delimiter |

**Key flags reference:**

| Flag | Effect |
|---|---|
| `-d` | Specify a **delimiter** between merged columns |
| `-s` | **Serial** merge; paste all lines of a single file into one line |

---

#### `fold` — Wrap long lines

| Command | Syntax | What it does |
|---|---|---|
| `fold` | `fold -w [n] file` | **Wraps** lines to a maximum width of `n` characters |

**Key flags reference:**

| Flag | Effect |
|---|---|
| `-w [n]` | Set maximum line **width** to `n` characters |
| `-s` | Break at **spaces** instead of mid-word |

---

#### `comm` — Compare two sorted files

| Command | Syntax | What it does |
|---|---|---|
| `comm` | `comm file1 file2` | Compares two **sorted** files and outputs 3 columns: lines unique to file1, unique to file2, and common to both |

**Key flags reference:**

| Flag | Effect |
|---|---|
| `-1` | Suppress column 1 (lines unique to file1) |
| `-2` | Suppress column 2 (lines unique to file2) |
| `-3` | Suppress column 3 (lines common to both) |
| `-12` | Prints only lines **common** to both files (Column 3) |

---

#### Other Utility Commands

| Command | Syntax | What it does |
|---|---|---|
| `echo` | `echo 'text'` | Displays strings or pipes them into pattern matchers |
| `xxd` | `xxd file` | Converts a file to a **hex dump** representation |
| `dpkg-query -W` | `dpkg-query -W \| grep 'pattern'` | Lists installed packages; commonly piped to `grep` for filtering |

**`echo` flags:**

| Flag | Effect |
|---|---|
| `-n` | Suppress trailing **newline** |
| `-e` | Enable interpretation of **escape sequences** |

### ⚖️ Key Comparisons & Distinctions

| Globs | Regular Expressions |
|---|---|
| Shell-level mechanism | Text-level mechanism |
| Used for **filename** matching | Used for **text content** matching |
| Expanded by the **shell** before command runs | Processed by the **command** (e.g., `grep`) |
| `*` matches any string of characters | `*` matches zero or more of the **preceding** character |
| Negation in brackets: `[!abc]` | Negation in brackets: `[^abc]` |

---

| BRE (Basic) | ERE (Extended) |
|---|---|
| Default engine for `grep`, `sed` | Enabled via `grep -E` or *deprecated* `egrep` |
| Grouping: `\( \)` | Grouping: `( )` |
| Quantifiers: `\+`, `\?`, `\{n,m\}` require escaping | Quantifiers: `+`, `?`, `{n,m}` used directly |
| Alternation: `\|` | Alternation: `|` |
| `+` is a literal character | `+` is a quantifier (one or more) |
| `\+` is a quantifier (one or more) | `\+` matches a literal plus sign |

---

| `^` as Anchor | `^` as Negation |
|---|---|
| At the **beginning** of a pattern: `^abc` | **Inside** square brackets as first character: `[^0-9]` |
| Matches the **start of a line** | Matches any character **NOT** in the set |

---

| `\b` (Word Boundary) | `^` / `$` (Line Anchors) |
|---|---|
| Matches a word boundary **anywhere** in a line | Matches the **start** / **end** of the entire line only |
| Position where word-char meets non-word-char | Position at line extremes |

---

### ⚠️ Common Exam Traps

- **Escaping Switch Gotcha:** In BRE, `+` is literal and `\+` is a quantifier; in ERE, `+` is a quantifier and `\+` matches a literal plus sign. This inversion applies to `?`, `{`, `}`, `(`, `)`, and `|` as well.

- **`grep` with `*` quantifier:** Searching for `grep 'a*'` will match **every line** in a file because the `*` quantifier allows for **zero** occurrences of `a` — so every line trivially matches.

- **Glob expansion failure:** If a glob pattern (like `*.txt`) matches no files, the shell passes the **literal string** `*.txt` to the command instead of an empty argument.

- **`cut` field numbering:** Fields in the `cut` command are numbered starting from **1**, not 0.

- **`tr` length mismatch:** If the second list in `tr` is shorter than the first, the **last character** of the second list is repeated to match the length of the first list.

- **`tr` range trap:** In `tr`, ranges like `1-26` represent the literal characters `1`, `2`, through `6` — **not** the number twenty-six. Use `1-9` for digits or explicit character lists.

- **`tr` mapping direction:** `tr` supports **many-to-one** mapping but does **NOT** support one-to-many mapping.

- **Glob negation vs. Regex negation:** Globs use `!` for negation inside brackets (`[!abc]`), while regex uses `^` (`[^abc]`). Mixing these up is a common MCQ mistake.

- **Locale-dependent ranges:** In `en_US.UTF-8`, `[a-d]` might match `[aBbCcDd]` due to locale collation rules. Use `LC_ALL=C` for strict ASCII ordering.

- **Skipping empty lines:** Use `egrep -v '^$'` (or `grep -Ev '^$'`) to filter out empty lines — `^$` matches a line with nothing between start and end.

## 🏆 Master Concept List — Top 25 Exam-Critical Terms

1. **`grep`** — The primary command-line utility for searching text using patterns
2. **BRE (Basic Regex)** — The default search engine requiring backslashes for grouping and most quantifiers
3. **ERE (Extended Regex)** — Advanced engine supporting `+`, `?`, and `|` directly; enabled via `grep -E`
4. **`^` (Caret)** — Anchor used to match the beginning of a line
5. **`$` (Dollar)** — Anchor used to match the end of a line
6. **`.` (Dot)** — Meta-character matching any single character except null or newline
7. **`*` (Asterisk)** — Quantifier matching zero or more occurrences of the preceding character
8. **`+` (Plus)** — Quantifier matching one or more occurrences of the preceding character (ERE / escaped BRE)
9. **`?` (Question Mark)** — Quantifier matching zero or one occurrence of the preceding character (ERE / escaped BRE)
10. **`[ ]` (Brackets)** — Matches any single character within the set; `[a-z]` denotes a range
11. **`[^ ]` (Negated Set)** — Matches any character NOT present in the brackets
12. **`\b` (Word Boundary)** — Anchor that identifies the start or end of a word
13. **`\1` to `\9` (Backreferences)** — Refers to the text matched by previous parenthesized groups
14. **`cut`** — Command used to extract specific fields or columns from structured text
15. **`tr`** — Command used for translating or deleting specific characters from a stream
16. **`[[:alpha:]]`** — Character class matching all alphabetic characters
17. **`[[:digit:]]`** — Character class matching all numeric digits `0-9`
18. **`|` (Alternation)** — Logical OR operator matching either the pattern to the left or the right
19. **`\{n,m\}`** — BRE syntax for specifying a range of occurrences (at least *n*, at most *m*)
20. **`grep -v`** — Flag used to display lines that do NOT match the specified pattern
21. **`grep -o`** — Flag used to extract and print only the exact matching text segment
22. **`paste`** — Command to merge lines of files horizontally
23. **`fold`** — Command used to wrap long lines to fit a specified character width
24. **PCRE** — Perl-Compatible engine allowing advanced regex features like look-aheads
25. **`-d` (Delimiter)** — Flag for `cut` and `paste` to define how data fields are separated
