## Week 5 — Shell Variables
> 💡 **One-line summary:** This week covers the creation, manipulation, and scope management of shell and environment variables, including advanced string processing, arithmetic, and array structures.

---

### 🔑 Core Concepts

#### Shell Variables
Key-value pairs that are local to the specific shell instance where they are created. They are **not** automatically passed to subshells or child processes.

> 📝 **Exam note:** Writing `var = value` (with spaces around `=`) will cause the shell to interpret `var` as a command — assignment requires **no spaces** around `=`.

---

#### Environment Variables
Variables created or promoted using the `export` command. Once exported, they are accessible to **all child processes and subshells** spawned by the current shell.

> 📝 **Exam note:** Modifying an exported variable's value inside a subshell does **not** update its value in the parent shell.

---

#### Variable Naming Rules
Variable names can contain alphanumeric characters and underscores. They **cannot start with a number** and must have **no spaces around the `=` sign** during assignment.

---

#### Subshells
A new shell instance created by the current shell. Variables must be exported to be visible in a subshell, and any modifications made inside a subshell **do not** propagate back to the parent shell.

---

#### Arithmetic Context
Bash treats variables as strings by default unless they are used within mathematical constructs like `$((...))` or `((...))`. Native Bash arithmetic supports **integers only** — floating-point math requires external tools like `bc`, `awk`, or `printf`.

> 📝 **Exam note:** Within `$(( ))`, comparison operators return `1` for true and `0` for false — this is the **inverse** of standard Bash exit codes where `0` means success.

---

#### Exit Status (`$?`)
A special variable storing the return code of the last executed command. `0` indicates success, while non-zero values indicate failure.

#### Specialized Exit Codes

| Code | Meaning |
|---|---|
| `0` | Success |
| `1` | General error |
| `2` | Misuse of shell builtins |
| `126` | Command found but **not executable** |
| `127` | Command **not found** |
| `130` | Process terminated by `Ctrl+C` (SIGINT) |
| `137` | Process killed via `kill -9` (SIGKILL) |

---

#### Parameter Expansion
A mechanism to retrieve, modify, or test variables using `${variable...}` syntax for tasks like setting defaults, substring extraction, pattern matching, and case modification.

---

#### Quoting Rules
- **Single quotes** (`'...'`): Everything is treated as a literal string — no variable expansion or interpretation occurs.
- **Double quotes** (`"..."`): Variables and command substitutions are expanded, but word splitting is suppressed.
- **No quotes**: Variables are expanded **and** subject to word splitting and globbing.

---

#### Multi-line Strings
If you open a quote and press Enter without closing it, the shell provides a `>` continuation prompt. The string includes the literal newlines until the closing quote is entered.

---

#### Command Substitution
Embed the output of a command inside another command or assignment using backticks `` `command` `` or the preferred `$(command)` syntax.

---

#### Indexed Arrays
Collections of elements identified by integer indices (starting at `0`). Indices **do not** need to be continuous (sparse arrays are allowed). Declared with `declare -a`.

---

#### Associative Arrays
Also known as hash maps, these use **strings as keys** instead of integers and store elements in **unordered** fashion. They **must** be declared with `declare -A` before use.

---

#### Brace Expansion
A mechanism for generating arbitrary strings or sequences. Examples: `{1..5}` generates `1 2 3 4 5`; `{1..11..2}` generates `1 3 5 7 9 11`; `{a,b}{1,2}` produces the Cartesian product `a1 a2 b1 b2`.

---

#### History Expansion
Uses the `!` operator to refer to and re-run previous commands from the shell's history list. `!!` re-runs the last command; `!n` re-runs command number `n`.

---

#### Process Control Signals

| Shortcut | Signal | Effect |
|---|---|---|
| `Ctrl+C` | SIGINT | Interrupt and terminate the foreground process |
| `Ctrl+Z` | SIGTSTP | Suspend the foreground process |
| `Ctrl+D` | EOF | Signal end-of-input (closes shell if at empty prompt) |
| `Ctrl+L` | — | Clear the terminal screen |
| `Ctrl+R` | — | Reverse-search through command history |
| `Ctrl+U` | — | Cut the entire line before the cursor |
| `Ctrl+W` | — | Cut the word before the cursor |

---

#### `PROMPT_COMMAND`
A special variable that stores a command or function to be executed **just before** the primary prompt (`PS1`) is displayed each time. Useful for dynamic prompt updates.

---

#### Number Bases in Arithmetic
Bash supports arbitrary number bases using the syntax `base#number` (bases 2–64). Hexadecimal uses the `0x` prefix; Octal uses a leading `0`.

> 📝 **Exam note:** `052` in arithmetic context is **octal** (= 42 in decimal), not 52. A leading `0` triggers octal interpretation.

---

#### Bash Internal Flags (`$-`)
The variable `$-` displays currently active shell option flags:

| Flag | Meaning |
|---|---|
| `h` | Hash — remember command locations |
| `i` | Interactive shell |
| `m` | Monitor — job control enabled |
| `B` | Brace expansion enabled |
| `H` | History expansion enabled |
| `s` | Read commands from stdin |

### ⌨️ Commands & Syntax

| Command | Syntax | What it does |
|---|---|---|
| `var=value` | `var=value` | Assigns a value to a local shell variable (no spaces allowed) |
| `export` | `export var` or `export var=val` | Converts a shell variable into an environment variable for subshell access |
| `echo` | `echo $var` or `echo ${var}` | Displays the value of a variable; `${var}` avoids ambiguity in concatenation |
| `unset` | `unset var` or `unset arr[i]` | Removes a variable or an array element from memory |
| `declare -i` | `declare -i var` | Restricts a variable to integer values only; non-integers are treated as `0` |
| `declare -r` | `declare -r var` | Makes a variable read-only; value cannot be changed or unset later |
| `declare -a` | `declare -a arr` | Declares an indexed array |
| `declare -A` | `declare -A arr` | Declares an associative array (hash map) — **mandatory** before use |
| `declare -l` | `declare -l var` | Automatically converts assigned value to lowercase |
| `declare -u` | `declare -u var` | Automatically converts assigned value to uppercase |
| `(( var++ ))` | `(( expression ))` | Performs C-style arithmetic without requiring `$` for variable access |
| `$(( ))` | `$(( expression ))` | Evaluates an arithmetic expression and returns the result |
| `[[ -v var ]]` | `[[ -v var ]]` | Returns `0` (success) if a variable is set/available in memory |
| `[[ -z ${var+x} ]]` | `[[ -z ${var+x} ]]` | Returns `0` if a variable is **not** set (unbound) |
| `bc` | `echo "scale=2; 10/3" \| bc` | External command for floating-point arithmetic not supported natively by Bash |
| `set` | `set` or `set -x` | Lists all variables/functions, or modifies shell behavior |
| `env` | `env` | Lists only exported environment variables |
| `printenv` | `printenv [VAR_NAME]` | Views one or all environment variables |
| `type` | `type -a echo` | Identifies if a command is a builtin or an external binary |
| `let` | `let "a = 5 + 2"` | Shell builtin for integer arithmetic assignment |
| `history` | `history` | Views past commands; `!n` or `!!` to re-run |
| `echo -e` | `echo -e "\n\t"` | Enables interpretation of escape sequences |

**Key flags reference:**

| Flag | Effect |
|---|---|
| `echo -n` | Suppress trailing newline |
| `echo -e` | Enable interpretation of backslash escape sequences |
| `echo -E` | Disable interpretation of escape sequences (default) |

| `set -C` | `noclobber` — prevent accidental file overwriting via redirection |
| `set +f` | Disable filename globbing |

**`echo` escape sequences reference:**

| Sequence | Effect |
|---|---|
| `\n` | Newline |
| `\t` | Horizontal tab |
| `\a` | Alert (bell) |
| `\b` | Backspace |
| `\c` | Suppress any further output in the string |
| `\r` | Carriage return — moves cursor to start of current line |
| `\f` | Form feed — moves cursor to next line without returning to column 0 |
| `\e` | Escape character |
| `\v` | Vertical tab |
| `\\` | Literal backslash |
| `\0nnn` | Octal value |
| `\xHH` | Hexadecimal value |

### Parameter Expansion Reference

#### Default Value Operators

| Syntax | Behavior |
|---|---|
| `${var:-default}` | Returns `default` if `var` is unset **or** null — does **not** assign |
| `${var-default}` | Returns `default` only if `var` is **unset** (null/empty is kept) |
| `${var:=default}` | Returns `default` **and assigns** it to `var` if unset or null |
| `${var=default}` | Assigns `default` only if `var` is **unset** |
| `${var:+alternate}` | Returns `alternate` if `var` is set and non-null |
| `${var+alternate}` | Returns `alternate` if `var` is set (even if null) |
| `${var:?message}` | Displays `message` and exits if `var` is unset or null |

#### String Operations

| Syntax | What it does |
|---|---|
| `${#var}` | Returns the length of the string stored in `var` |
| `${!var*}` | Returns names of all variables matching prefix `var` |
| `${var:offset:len}` | Substring extraction starting at `offset` for `len` characters |
| `${var: -5}` | Extracts the last 5 characters (**space before `-` is required**) |

#### Pattern Matching (Prefix/Suffix Removal)

| Syntax | What it does |
|---|---|
| `${var#pattern}` | Removes the **shortest** matching prefix |
| `${var##pattern}` | Removes the **longest** matching prefix |
| `${var%pattern}` | Removes the **shortest** matching suffix |
| `${var%%pattern}` | Removes the **longest** matching suffix |

#### Substitution

| Syntax | What it does |
|---|---|
| `${var/pattern/string}` | Replace **first** match |
| `${var//pattern/string}` | Replace **all** matches |
| `${var/#pattern/string}` | Replace match at **beginning** only |
| `${var/%pattern/string}` | Replace match at **end** only |

#### Case Modification

| Syntax | What it does |
|---|---|
| `${var^}` | Uppercase **first** character |
| `${var^^}` | Uppercase **all** characters |
| `${var,}` | Lowercase **first** character |
| `${var,,}` | Lowercase **all** characters |

### Arithmetic Operators in `(( ))`

| Operator | Meaning |
|---|---|
| `**` | Exponentiation |
| `~` | Bitwise NOT |
| `&` | Bitwise AND |
| `\|` | Bitwise OR |
| `^` | Bitwise XOR (*not* exponentiation) |
| `++` / `--` | Increment / Decrement |
| `,` | Comma operator (evaluate multiple expressions) |

> 📝 **Exam note:** `^` in arithmetic context is **bitwise XOR**, not exponentiation. Use `**` for powers.

### Array Operations Reference

| Syntax | What it does |
|---|---|
| `arr=(val1 val2 val3)` | Initialize an indexed array |
| `arr+=(val4)` | Append to an array |
| `${arr[0]}` | Access element at index 0 |

### ⚖️ Key Comparisons & Distinctions

| Concept A | Concept B |
|---|---|
| **Shell variables** — local to the current process only | **Environment variables** — inherited by all child processes via `export` |
| `${var:-default}` — returns default without changing `var` | `${var:=default}` — returns default **and** assigns it to `var` |
| `${var-default}` — triggers only if `var` is **unset** | `${var:-default}` — triggers if `var` is unset **or** null (empty) |
| `${var#pattern}` — removes **shortest** prefix match | `${var##pattern}` — removes **longest** prefix match |
| `${var%pattern}` — removes **shortest** suffix match | `${var%%pattern}` — removes **longest** suffix match |
| `"$*"` — treats all arguments as **one string** | `"$@"` — treats each argument as a **separate quoted string** |
| `set` — lists **all** variables and functions | `env` / `printenv` — lists only **exported** environment variables |
| `"${arr[*]}"` — yields **one single string** of all elements | `"${arr[@]}"` — yields **multiple strings**, one per element |
| `Ctrl+U` — cuts the **entire line** before the cursor | `Ctrl+W` — cuts only the **word** before the cursor |
| `unset var` — completely removes the variable | `var=""` — sets `var` to an empty string (variable still exists) |
| `echo` (builtin) — check with `help echo` | `echo` (external `/bin/echo`) — check with `man echo` |

### ⚠️ Common Exam Traps

- **Spaces in Assignment:** Writing `var = value` (with spaces) will cause the shell to try executing `var` as a command rather than performing an assignment. Correct syntax: `var=value`.

- **Subshell Isolation:** Changing an exported variable's value inside a subshell **does not** update its value in the parent shell. Changes are lost when the subshell exits.

- **Integer Restriction Gotcha:** If a variable is declared with `declare -i`, assigning a string like `"Hello"` sets the variable's value to `0` rather than throwing an error.

- **Negative Slicing Space:** When using negative offsets for substrings (e.g., `${var: -5}`), a **space is required** before the minus sign to avoid confusion with the `:-` default value operator.

- **Read-Only Cannot Be Unset:** A variable declared with `declare -r` cannot be removed even with `unset`. It persists for the life of the shell session.

- **Arithmetic Comparison Inversion:** Within `$(( ))`, operators like `>` or `==` return `1` for true and `0` for false, which is the **inverse** of standard Bash exit codes where `0` = success.

- **Multi-line Echo Trap:** If you open a quote and press Enter, the shell provides a `>` continuation prompt; the string includes the literal newlines until the closing quote is entered.

- **Octal Surprise:** A leading `0` in arithmetic context triggers **octal** interpretation — `052` evaluates to decimal `42`, not `52`. Similarly, `0x` denotes hexadecimal.

- **Bitwise XOR vs. Exponentiation:** In arithmetic context, `^` is **bitwise XOR**, not exponentiation. Use `**` for powers.

- **`PATH` Manipulation:** Adding the current directory via `PATH=$PATH:$PWD` can be a security risk if untrusted directories are included.

## 🏆 Master Concept List — Top 25 Exam-Critical Terms

1. **`$?`** — Variable holding the exit status of the most recently executed command
2. **`export`** — Command to make a local variable available to all child processes/subshells
3. **`PATH`** — Environment variable containing a colon-separated list of directories searched for executables
4. **`declare -A`** — Mandatory command for creating associative arrays (hash maps)
5. **`${#var}`** — Parameter expansion that returns the length of a string or array
6. **`$(( ))`** — Syntax for evaluating integer arithmetic expressions
7. **`${var:-val}`** — Returns `val` if `var` is unset or null, but does not assign it
8. **`${var:=val}`** — Sets `var` to `val` if it is currently unset or null
9. **`unset`** — Command to delete a variable or specific array index from memory
10. **`$@`** — Special variable representing all script arguments as individual strings
11. **`PS1`** — Variable defining the primary prompt string of the shell
12. **`$$`** — Variable containing the Process ID (PID) of the current shell
13. **`${var:offset:len}`** — Substring expansion starting at `offset` for `len` characters
14. **`declare -i`** — Attribute that forces a variable to behave as an integer
15. **`${var#pattern}`** — Removes the shortest matching prefix from a variable
16. **`${var%pattern}`** — Removes the shortest matching suffix from a variable
17. **`$0`** — Stores the name of the current script or shell being executed
18. **`$RANDOM`** — Returns a pseudo-random integer between 0 and 32767
19. **`declare -r`** — Sets a variable to read-only; it cannot be modified or deleted
20. **`{start..end}`** — Brace expansion for generating sequences of numbers or letters
21. **`!number`** — History expansion to re-run a specific command by its history index
22. **`PWD`** — Environment variable storing the current absolute working directory
23. **`env`** — External command to list exported environment variables
24. **`(( ))`** — Arithmetic command used for testing or modifying variables (e.g., increments)
25. **`[[ -v var ]]`** — Conditional expression used to check if a variable has been defined
