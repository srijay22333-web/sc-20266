# 🎓 Student Grade Classification using AWK

---

## 📝 Problem Statement

You are given a file where each line contains:

* A **student identifier** (single character A–Z)
* Scores in **three subjects**:

  * English
  * Mathematics
  * Science

All values are **space-separated**.

---

### 🎯 Your Task

For each student:

* Calculate the **average of three scores**
* Assign grade based on average:

| Average Range | Grade |
| ------------- | ----- |
| ≥ 80          | A     |
| ≥ 60 and < 80 | B     |
| ≥ 50 and < 60 | C     |
| < 50          | FAIL  |

---

### 📌 Output Format

Append the grade to each line:

```text
[original line] : [Grade]
```

---

## 📥 Sample Input

```text id="gr1"
A 25 27 50
B 35 37 75
C 75 78 80
D 99 88 76
```

---

## 📤 Sample Output

```text id="gr2"
A 25 27 50 : FAIL
B 35 37 75 : FAIL
C 75 78 80 : B
D 99 88 76 : A
```

---

## 💻 Solution

```bash id="gr3"
awk '
BEGIN {
    FS = " "
}

{
    avg = ($2 + $3 + $4) / 3

    if (avg >= 80) {
        grade = "A"
    } 
    else if (avg >= 60) {
        grade = "B"
    } 
    else if (avg >= 50) {
        grade = "C"
    } 
    else {
        grade = "FAIL"
    }

    printf "%s : %s\n", $0, grade
}
'
```

---

## 🔍 Explanation

---

### 🔹 Field Separator

```awk id="gr4"
FS = " "
```

👉 Splits input by space

* `$1` → Identifier
* `$2, $3, $4` → Scores

---

### 🔹 Calculate Average

```awk id="gr5"
avg = ($2 + $3 + $4) / 3
```

👉 Computes average of 3 subjects

---

### 🔹 Grade Conditions

```awk id="gr6"
if (avg >= 80) → A
else if (avg >= 60) → B
else if (avg >= 50) → C
else → FAIL
```

---

### 🔹 Print Output

```awk id="gr7"
printf "%s : %s\n", $0, grade
```

👉 Prints original line + grade

---

## 🎯 Key Idea

👉 Use **if-else ladder** based on average

---

## ⚠️ Important Points

* Conditions are checked **top to bottom**
* First true condition is selected
* Use `printf` for formatted output

---

## 🧠 Memory Trick

👉 **80 → A, 60 → B, 50 → C, else FAIL**
