# ⚠️ Detect Missing Scores using AWK

---

## 📝 Problem Statement

You are given a file where each line contains:

* A **student identifier** (single character)
* Scores in **three subjects**:

  * English
  * Mathematics
  * Science

All values are **space-separated**.

---

### 🎯 Your Task

Identify students whose records are **incomplete**, i.e.:

* One or more of the **three scores is missing**

For each such student, print:

```text
Not all scores are available for [Identifier]
```

---

## 📥 Sample Input

```text id="ms1"
A 25 27 50
B 35 75
C 75 78 
D 99 88 76
```

---

## 📤 Sample Output

```text id="ms2"
Not all scores are available for B
Not all scores are available for C
```

---

## 💻 Solution

```bash id="ms3"
awk '
BEGIN {
    FS = " "
}

(NF < 4) {
    print "Not all scores are available for", $1
}
'
```

---

## 🔍 Explanation

---

### 🔹 Field Separator

```awk id="ms4"
FS = " "
```

👉 Splits input by space

So:

* `$1` → Identifier
* `$2, $3, $4` → Scores

---

### 🔹 NF (Number of Fields)

```awk id="ms5"
NF
```

👉 Represents number of fields in current line

---

### 🔹 Condition

```awk id="ms6"
NF < 4
```

👉 Means:

* Less than 4 fields → missing score

---

### 🔹 Output

```awk id="ms7"
print "Not all scores are available for", $1
```

👉 Prints student identifier

---

## 🎯 Key Idea

👉 Count fields using `NF` to detect missing data

---

## ⚠️ Important Points

* Full record → `NF = 4`
* Missing data → `NF < 4`
* Works even if last field is empty

---

## 🧠 Memory Trick

👉 **NF < expected → data missing**

---
