# 🎓 Student Pass/Fail Classification using AWK

---

## 📝 Problem Statement

You are given a file where each line contains:

* A **student identifier** (single character)
* Scores in **three subjects**:

  * English
  * Mathematics
  * Science

All values are **space-separated**.

---

### 🎯 Your Task

For each student:

* If the student scores **50 or more in all three subjects** → print **Pass**
* Otherwise → print **Fail**

---

## 📥 Sample Input

```text id="pf1"
A 25 27 50
B 35 37 75
C 75 78 80
D 99 88 76
```

---

## 📤 Sample Output

```text id="pf2"
A : Fail
B : Fail
C : Pass
D : Pass
```

---

## 💻 Solution

```bash id="pf3"
awk '

BEGIN {
    FS = " "
}

{
    if ($2 >= 50 && $3 >= 50 && $4 >= 50) {
        print $1 " : Pass"
    } 
    else {
        print $1 " : Fail"
    }
}

'
```

---

## 🔍 Explanation

---

### 🔹 Field Separator

```awk id="pf4"
FS = " "
```

👉 Splits input by space

So:

* `$1` → Identifier
* `$2` → English
* `$3` → Math
* `$4` → Science

---

### 🔹 Condition Check

```awk id="pf5"
$2 >= 50 && $3 >= 50 && $4 >= 50
```

👉 Student passes only if:

* All three scores ≥ 50

---

### 🔹 Output

```awk id="pf6"
print $1 " : Pass"
```

👉 Prints:

```text id="pf7"
C : Pass
```

---

## 🎯 Key Idea

👉 Use **logical AND (`&&`)** to check all conditions

---

## ⚠️ Important Points

* All subjects must satisfy condition
* Even one subject < 50 → Fail
* `$1, $2, $3, $4` represent fields

---

## 🧠 Memory Trick

👉 **All ≥ 50 → Pass, else Fail**

---

## 🚀 Final Insight

This problem teaches:

* Field extraction
* Conditional checks
* Logical operators (`&&`)
