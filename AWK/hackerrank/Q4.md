# 🔗 Concatenate Every Two Lines using AWK

---

## 📝 Problem Statement

You are given a file where each line contains:

* A **student identifier**
* Scores in **three subjects**

All values are **space-separated**.

---

### 🎯 Your Task

* Combine every **two consecutive lines**
* Join them using a **semicolon (`;`)**
* Print the result

---

### 📌 Output Format

```text
[line1];[line2]
```

---

## 📥 Sample Input

```text id="ct1"
A 25 27 50
B 35 37 75
C 75 78 80
D 99 88 76
```

---

## 📤 Sample Output

```text id="ct2"
A 25 27 50;B 35 37 75
C 75 78 80;D 99 88 76
```

---

## 💻 Solution

```bash id="ct3"
awk '
{
    if (NR % 2 == 1) {
        printf "%s;", $0
    } 
    else {
        print $0
    }
}
'
```

---

## 🔍 Explanation

---

### 🔹 NR (Record Number)

```awk id="ct4"
NR
```

👉 Represents current line number

---

### 🔹 Odd Line Check

```awk id="ct5"
NR % 2 == 1
```

👉 True for:

* Line 1
* Line 3
* Line 5

---

### 🔹 Print Without Newline

```awk id="ct6"
printf "%s;", $0
```

👉 Prints:

* First line
* Adds `;`
* No newline

---

### 🔹 Print Second Line

```awk id="ct7"
print $0
```

👉 Completes the pair and moves to next line

---

## 🎯 Key Idea

👉 Use **NR % 2** to group lines in pairs

---

## ⚠️ Important Points

* `printf` → does NOT add newline
* `print` → adds newline
* Always alternate between them

---

## 🧠 Memory Trick

👉 **Odd line → hold + ";"**
👉 **Even line → complete pair**

---

## 🚀 Final Insight

This problem teaches:

* Line-based grouping
* Using `NR` for control
* Mixing `printf` and `print`
