## Highlight Word (Case-Insensitive)

# Problem Statement

You are given multiple lines of text as input. Each line may contain the word **"thy"** appearing one or more times.

Your task is to process each line and **highlight all occurrences** of the word **"thy"** by wrapping them with **curly braces `{}`**.

The replacement must be:

* Case-insensitive (e.g., `thy`, `Thy`, `THY`, etc.)
* Applied only to the **whole word "thy"**
* Not applied to substrings (e.g., "thyme", "anything" should remain unchanged)

---

# Sample Input

```
Feed'st thy light's flame with self-substantial fuel,
Thy self thy foe, to thy sweet self too cruel:
thy Thy tHy THY theory
```

---

# Sample Output

```
Feed'st {thy} light's flame with self-substantial fuel,
{Thy} self {thy} foe, to {thy} sweet self too cruel:
{thy} {Thy} {tHy} {THY} theory
```

---

# Solution

```bash
sed 's/\<[Tt][Hh][Yy]\>/{&}/g'

or 

sed 's/thy/{&}/gi'
```

---

# Explanation

* `s` → Substitute command in sed
* `\<[Tt][Hh][Yy]\>` → Matches the **whole word "thy"** in all cases
* `{&}` → Wraps the matched word with `{}` while preserving original case
* `g` → Replaces **all occurrences per line**

* `i` → **case insensitive flag** mathces to thy THY Thy
