## Mask Credit Card Numbers

# Problem Statement

You are given multiple lines of credit card numbers as input. Each line contains a credit card number in the format:

```
dddd dddd dddd dddd
```

Your task is to **mask the first 12 digits** of each credit card number with `*` and print the result.

The masking must:

* Replace the **first three groups** (12 digits) with `**** **** ****`
* Keep the **last 4 digits unchanged**
* Preserve the original format with spaces

---

# Sample Input

```id="cc1"
1234 5678 9101 1234
2999 5178 9101 2234
9999 5628 9201 1232
8888 3678 9101 1232
```

---

# Sample Output

```id="cc2"
**** **** **** 1234
**** **** **** 2234
**** **** **** 1232
**** **** **** 1232
```

---

# Solution

```bash id="cc3"
sed 's/\([0-9]\{4\}\) \([0-9]\{4\}\) \([0-9]\{4\}\)/**** **** ****/'

or ERE

sed -E 's/([0-9]{4}) ([0-9]{4}) ([0-9]{4})/**** **** ****/'
```

---

# Explanation

* `s` → Substitute command in sed

* `\([0-9]\{4\}\)` → Matches a group of **4 digits**

  * `\{4\}` → exactly 4 times
  * `()` → capture group

* There are **3 groups matched**:

  * first 4 digits
  * second 4 digits
  * third 4 digits

* Space `" "` is explicitly matched between groups

* Replacement:

  ```bash
  **** **** ****
  ```

  replaces first 12 digits

* The **last 4 digits remain unchanged**

---

## 🧠 Key Concept

👉 This uses **grouping + pattern matching** to target only first 12 digits
