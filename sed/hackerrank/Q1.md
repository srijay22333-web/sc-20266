# Problem Statement

You are given multiple lines of text as input. Each line may contain the word "the" appearing one or more times.

Your task is to process each line and replace only the **first occurrence** of the word "the" with the word "this".

The replacement must be:
- Case-sensitive
- Applied only to the **whole word "the"**
- Not applied to substrings (e.g., "theme", "thee" should remain unchanged)

---

# Instructions

Write your solution using a **sed command**.

The command should read from standard input and print the processed output.

The command will be executed as follows:


---

# Sample Input

```
But as the riper should by time decease,
To eat the world's due, by the grave and thee.
the theory of the them
```

---

# Sample Output

```
But as this riper should by time decease,
To eat this world's due, by the grave and thee.
this theory of the them
```

---

# Solution

```bash
sed 's/\<the\>/this/'
```

---

# Explanation

* `s` → Substitute command in sed
* `\<the\>` → Matches the **whole word "the"** only
* `this` → Replacement string
* By default, sed replaces only the **first occurrence per line**
