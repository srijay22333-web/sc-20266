## Reverse Credit Card Segments


# Problem Statement

You are given multiple lines of credit card numbers as input. Each line contains a credit card number in the format:

```id="rev1"
dddd dddd dddd dddd
```

Your task is to **reverse the order of the four segments** in each credit card number.

The transformation must:

* Reverse the **segment order**
* Keep each group of 4 digits intact
* Preserve spacing between groups

---

# Sample Input

```id="rev2"
1234 5678 9101 1234
2999 5178 9101 2234
9999 5628 9201 1232
8888 3678 9101 1232
```

---

# Sample Output

```id="rev3"
1234 9101 5678 1234
2234 9101 5178 2999
1232 9201 5628 9999
1232 9101 3678 8888
```

---

# Solution

```bash id="rev4"
sed 's/\([0-9]\{4\}\) \([0-9]\{4\}\) \([0-9]\{4\}\) \([0-9]\{4\}\)/\4 \3 \2 \1/'

sed -E 's/([0-9]{4}) ([0-9]{4}) ([0-9]{4}) ([0-9]{4})/\4 \3 \2 \1/'
```

---

# Explanation

* `s` → Substitute command in sed

* `\([0-9]\{4\}\)` → Matches a group of **4 digits**

  * Each group is captured using `()`

* Total groups:

  * `\1` → first segment
  * `\2` → second segment
  * `\3` → third segment
  * `\4` → fourth segment

---

### 🔁 Reordering using Backreferences

```bash id="rev5"
\4 \3 \2 \1
```

👉 This prints:

* 4th group first
* then 3rd
* then 2nd
* then 1st

---

## 🧠 Key Concept

👉 Uses **groups + backreferences** to rearrange text
